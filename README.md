# Webový projekt (ve vývoji)

Tento repozitář obsahuje zdrojové soubory webového projektu, který je ve vývoji. Bližší informace o produktu, jeho rozsahu ani plánech zatím nezveřejňujeme.

> **Stav: ve vývoji.** Obsah repozitáře se může kdykoli změnit a nic z něj není nabídkou ani závazkem.

## Struktura repozitáře

| Soubor | Obsah |
| --- | --- |
| `index.html` | vstupní stránka s přihlášením (přístup jen pro pozvané uživatele) |
| `home.html` | obsah webu, který se zobrazí po přihlášení |
| `CNAME` | nastavení vlastní domény pro GitHub Pages |
| `.gitignore` | soubory, které se necommitují (IDE, build výstupy, lokální konfigurace) |

## Poznámky

- Repozitář je veřejný pouze z technických důvodů (hosting statických stránek), nejde o veřejnou nabídku produktu.
- Zdrojové kódy aplikace nejsou součástí tohoto repozitáře.
- Přístup do aplikace je možný pouze po přihlášení.
